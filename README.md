## Zara Hair — Link-in-Bio & Bundle Storefront


A fast, mobile-first single-page storefront built for Zara Hair, designed specifically for Instagram and TikTok bio links. Customers can browse top hair bundles, view clear delivery timelines, and place pre-filled orders directly via WhatsApp in a single tap.

## ✨ Features

- Mobile-First Design (360px+): Optimized for small smartphone screens with zero horizontal scrolling and generous, thumb-friendly tap targets (50px+ button height).
- Signature Bundle Cards: Showcases top hair bundles with high-resolution imagery, length in inches, pricing in Naira (₦), and instant fallback placeholders.
- Pre-Filled WhatsApp Checkout: Each Order on WhatsApp button opens a WhatsApp chat (wa.me) with the exact bundle name, length, and price already typed out.
Clear Delivery Policy: Highlights Lagos delivery timelines, interstate shipping details, and buyer-paid delivery fee terms.
- Offline-Ready Inline SVGs: All icons (verification crown, delivery truck, WhatsApp, Instagram, and TikTok) use inline SVGs so they never break offline or across different folders.
- Full-Width Social Links: Stacked Instagram and TikTok buttons for effortless navigation.


## 🛠️ Built With
- HTML5 — Semantic structure
- Tailwind CSS (via CDN) — Utility-first responsive styling
- Google Fonts — Cormorant Garamond (serif headings) & Plus Jakarta Sans (clean body text)
- Inline SVGs — Crisp, dependency-free vector icons


## 🚀 Getting Started

### 1. Clone or Download
Clone this repository or download `zara_hair.html` (or rename it to `index.html` for web hosting):

`git clone https://github.com/your-username/zara-hair.git`



## 2. Customize Your Details
Open the HTML file in any code editor (VS Code, Spck Editor, or TrebEdit) and update the following placeholders:

- WhatsApp Number: Search for 23480000000while writing p00 in the https://wa.me/... links and replace it with your active WhatsApp number in international format (without the + sign).
- Bundle Photos & Prices: Update the src image URLs, lengths, and prices inside the three <article> cards to match your current inventory.
- Social Handles: Update https://instagram.com and https://tiktok.com with your exact profile URLs.

## 3. Deploy for Free on GitHub Pages
Rename zara_hair.html to index.html in the root of your repository.
- Go to your repository Settings → Pages.
Under Build and deployment, select Deploy from a branch, choose main (or master), and click Save.
- Copy your live GitHub Pages URL and paste it directly into your Instagram and TikTok bio.
